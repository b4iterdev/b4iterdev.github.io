# Nguyen Minh Thai - Portfolio

A premium, cinematic personal portfolio website for Nguyen Minh Thai, positioned as a Creative Technologist.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animation**: GSAP (ScrollTrigger) & Framer Motion
- **Icons**: Lucide React

## Scripts
- `npm run dev`: Start the development server
- `npm run build`: Build the production application
- `npm run start`: Start the production server
- `npm run lint`: Run ESLint

## Asset Policy
This project uses abstract mockups and placeholders for project visuals to maintain a clean, cinematic aesthetic without relying on potentially unavailable or inconsistent screenshots.
